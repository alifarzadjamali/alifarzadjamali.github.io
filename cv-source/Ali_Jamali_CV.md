**Evidence-Constrained Multimodal Fashion Recommendation** *\| MPhil thesis project*

- Built a multimodal fashion recommender using CLIP image and text embeddings for similarity search, then reranked candidates using a 200-rule fashion knowledge base. Generated explanations with RAG using the exact rules behind each recommendation.

- Verified every explanation automatically. Extracted atomic claims and checked each one against the rule evidence, across 1,000 test cases and three open-source LLMs.

- Supplying the exact rule trace raised trace-supported claims by 21 percentage points (95% CI 19.7 to 22.4). Reported that reranking itself did not improve retrieval metrics.

**LLM Output Homogenization** *\| NLP & LLM Evaluation*

*(Manuscript in preparation for journal submission)*

- Compared text generated by multiple LLMs across different datasets to study similarities and differences in their outputs.

- Used text embeddings and semantic similarity analysis to evaluate response diversity and consistency.

[GitHub: LLM-output-homogenization](https://github.com/alifarzadjamali/LLM-output-homogenization)

**RepBench-Fashion** *\| Research paper (in preparation)*

- Built a controlled benchmark of seven frozen visual representations, including ResNet50, DINOv3, CLIP and SigLIP2, for fashion outfit compatibility. Tested across Polyvore, IQON3000 and a human-grounded external set, with no item or outfit overlap between training and test.

- Found that contrastive vision-language models beat ResNet50 and DINOv3 on both datasets (ROC-AUC about 0.89 against 0.69 on Polyvore). Fashion-specialised models were not consistently better. Used bootstrap intervals with Holm correction.
